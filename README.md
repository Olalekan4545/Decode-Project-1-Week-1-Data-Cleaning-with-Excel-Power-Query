# Decode-Project-1-Week-1-Data-Cleaning-with-Excel-Power-Query

## Project Overview
This project documents my Week 1 data-cleaning task for Decode Project 1. The objective was to clean, standardize, and validate a dataset using Microsoft Excel Power Query to improve data quality and prepare it for further analysis.

Tool Used: Microsoft Excel Power Query
Dataset Size: 100 Rows × 14 Columns

#

## 🎯 Project Objectives

- Identify and handle missing values.
- Check data quality and consistency.
- Standardize text and date formats.
- Validate the dataset after cleaning.

## 🛠️ Data Cleaning Process

1. Data Import

I loaded the dataset into Power Query through Microsoft Excel to begin the data-cleaning process.

2. Data Profiling

I used the Column Profile feature in Power Query to examine each column for missing values, errors, inconsistencies, and potential data-quality issues.

3. Handling Missing Values

I identified 252 null values in the "Coupon Code" column and replaced them with "No Coupon Code" to make the absence of coupon codes explicit and maintain consistency in the dataset.

4. Text Standardization

I applied proper capitalization to the "Coupon Code" column to ensure consistent text formatting.

5. Date Formatting

I corrected the date column's format to ensure that the dates followed a consistent and appropriate format.

6. Data Validation

After cleaning, I used the Column Profile feature to review the columns and validate the dataset's quality, checking for errors and inconsistencies.

#

## 📊 Key Outcomes

- Reviewed a dataset containing 100 rows and 14 columns.
- Identified and handled 252 null values in the "Coupon Code" column.
- Standardized text formatting in the "Coupon Code" column.
- Corrected the date column's format.
- Applied data profiling and validation techniques to improve data quality.
